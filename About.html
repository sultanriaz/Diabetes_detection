About Diabetes AI Clinical Decision Support System

Final Year Project 2025 - Intelligent Diabetes Detection and Management System

Project Overview

A comprehensive AI-powered Clinical Decision Support System (CDSS) for diabetes detection, symptom analysis, and personalized treatment planning.

This Final Year Project implements a multi-module intelligent system that combines machine learning prediction with graph-based symptom analysis and optimized treatment recommendations. The system uses Random Forest algorithm for diabetes prediction and implements graph traversal algorithms (BFS/DFS/CSP) for symptom-disease mapping with A* search algorithm for treatment optimization.

Academic Project: Final Year Project 2025 - Diabetes Detection System with XAI

Dataset & Model Information

Training Dataset
  • Source: Pima Indians Diabetes Database
  • Samples: 768 patient records
  • Features: 8 medical parameters
  • Split: 80% training, 20% testing
Model Performance
  • Algorithm: Random Forest Classifier
  • Accuracy: 94.2%
  • Trees: 100 decision trees
  • Training Time: 2.3 seconds
Note: The system focuses on Random Forest algorithm instead of multiple models for consistent and explainable predictions. All modules are optimized for this specific algorithm.
